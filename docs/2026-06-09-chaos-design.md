# /chaos design (2026-06-09)

Brainstormed and approved in session. Decisions:

- **Three behaviors, dynamic dispatch, no flags**: remix (target named) > inject (build in flight) > deal (blank slate). Luke: "I like all three... applied dynamically."
- **Confidence-scaled taste gate**: apply directly when clear + additive + reversible; deal 2-3 options when in doubt. Luke: "B if in doubt, A/C if clear."
- **Home**: public plugin `actually-useful-ai/chaos` (option A over private skill or humanize bundling).
- **Shape**: approach 3 of 3 ("dealer + harvest loop"): a curated deck seeded from Luke's shipped work, plus a rule that every shipped /chaos result appends a card. Chosen over deck-only (goes stale) and pure-judgment (drifts generic): the deck makes the skill more like Luke over time.
- **Rules source**: the humanize plugin's "Voice: A Little Chaos" section plus precedents from the bzbzbzbz build (a11y as part of the bit, escalation as comic engine, register check).

Out of scope: scripts, MCP, any engine. Markdown only.
